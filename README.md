# TeamFlow

TeamFlow is a full-stack project management platform built to explore
production-oriented backend development with Node.js and TypeScript.

## Tech Stack

### Frontend

- React
- TypeScript

### Backend

- Node.js
- Express
- TypeScript

### Database

- PostgreSQL
